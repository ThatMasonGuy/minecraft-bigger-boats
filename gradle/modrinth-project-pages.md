## Bigger Boats

- Modrinth project name: `Bigger Boats`
- Project ID: `AqXkZezn`

## Summary

Let up to four players ride in one vanilla boat. Server-side first, optional
client polish.

## Description

Bigger Boats keeps vanilla boats simple, but makes them better for small groups.
Install it on a Fabric server and up to four players can ride in the same boat.
No new recipe, no new boat item, no custom entity to teach players about.

The server controls the important behavior, so unmodded clients can still join.
Players who install the mod on their client get cleaner visuals: extra riders
are spaced out and the boat stretches slightly when a third or fourth passenger
is aboard.

## Features

- Four players per vanilla boat
- Server-side gameplay support
- Optional client-side visual polish
- Normal one- and two-passenger boats stay visually normal
- Dynamic client-side stretch for three and four passengers
- No extra crafting recipes or replacement boat items

## Install Note

For multiplayer, install Bigger Boats on the Fabric server. Clients do not need
the mod to connect or ride, but installing it client-side improves how crowded
boats look.

Fabric API is required.
