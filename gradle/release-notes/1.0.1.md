# Bigger Boats 1.0.1

- Adds support for Minecraft `26.2`.
- Adds support for Minecraft `26.3-snapshot-1`.
- Keeps Minecraft `26.1`, `26.1.1`, and `26.1.2` support on the current 26.x
  compatibility lane.
- No gameplay behavior changed: vanilla boats still carry up to four players on
  servers, and the optional client install still improves crowded-boat visuals.
