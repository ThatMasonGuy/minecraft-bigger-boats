# Bigger Boats 1.0.0

- Lets up to four players ride in one vanilla boat.
- Server-side first: install on the Fabric server for gameplay support.
- Clients can stay unmodded, though extra riders may visually overlap with
  vanilla rendering.
- Optional client install adds cleaner seat spacing and stretches the rendered
  boat when three or four passengers are aboard.
- Does not add new recipes, items, blocks, or custom boat entities.
